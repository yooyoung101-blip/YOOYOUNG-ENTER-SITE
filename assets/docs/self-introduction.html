01 / STORY

5년 6개월 동안 아이돌 데뷔를 준비했습니다. 준비해온 데뷔가 무산된 뒤에는 음악을 멀리했고, 새로운 진로를 찾으며 서비스 현장과 콘텐츠·비주얼 작업을 경험했습니다. 서로 다른 환경에서도 목표를 정하면 필요한 일을 직접 배우고 결과물까지 완성하는 방식은 같았습니다.

다시 음악 제작을 시작한 뒤에는 송라이팅, 가이드 보컬, 송캠프, 리스닝 세션과 발매 프로젝트까지 작업 범위를 넓혔습니다. 직접 데모를 만들고 수정하는 과정에서 보컬, 훅, 리듬, 레퍼런스와 파일 버전이 실제 결과물에 어떤 영향을 주는지 익혔습니다.

02 / WORK

저는 음악과 콘텐츠를 따로 보지 않습니다. 곡을 만들 때에는 보컬과 퍼포먼스에서 보일 장면을 함께 생각하고, 비주얼 작업에서는 음악의 무드와 화면의 질감을 맞추는 방식으로 접근해왔습니다. 송캠프와 공동 제작에서는 팀의 역할을 확인하고 필요한 포지션을 맡아 작업을 완성했습니다.

앞으로도 새로운 환경에서 필요한 실무를 빠르게 익히고, 제작 과정의 디테일을 놓치지 않는 사람으로 일하고 싶습니다.
