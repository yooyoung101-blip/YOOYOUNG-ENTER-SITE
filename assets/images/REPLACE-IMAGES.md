# Image replacement map

The current site uses temporary downloaded reference images under `assets/images/`.
Before a final public release, replace those files with approved final images and keep similar aspect ratios.

Recommended local paths:
- `assets/images/performance-editorial.jpg` — performance/editorial image
- `assets/images/studio-editorial.webp` — studio/editorial image
- `assets/images/song-camp.jpg` — song camp / music image
- `assets/images/content-visual.jpg` — content / visual image
- `assets/images/urban-visual.jpg` — city / visual image

Suggested minimum export size: 1800px on the long edge, JPEG quality 82–90.
Avoid putting text inside the image because the site already overlays typography.
