# DEPLOY — GitHub Pages

Target repository: `yooyoung101-blip/YOOYOUNG-ENTER-SITE`

## 1. Upload
Upload the **contents** of this folder to the repository root. Do not upload the ZIP itself.

The root should contain at least:

- `index.html`
- `404.html`
- `.nojekyll`
- `favicon.svg`
- `site.webmanifest`
- `robots.txt`
- `assets/`
- `projects/`

## 2. Enable GitHub Pages
GitHub repository → **Settings → Pages**

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**
- Save

Expected public address:

`https://yooyoung101-blip.github.io/YOOYOUNG-ENTER-SITE/`

## 3. Final browser QA after deployment
Open the deployed URL in:

- Mac Safari
- Mac Chrome
- iPhone Safari

Check HOME, INDEX, PROFILE, EXPERIENCE, WORKS, MUSIC, DOCUMENTS and CONTACT.

Also check direct links:

- `#profile`
- `#works`
- `#music`
- `#docs`
- `projects/somi/`

## 4. Privacy
The current build uses `noindex,nofollow`, so the intent is a recruiter-link portfolio rather than a search-indexed public site. This does not make the URL private; anyone with the URL can still open it.
